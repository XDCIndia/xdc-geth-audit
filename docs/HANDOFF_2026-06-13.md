### Why modern observers can't follow legacy chain (root cause + fix)

Modern's `localnet5151Constants.TIPSigning = 0` activated the gasless sign-tx path from genesis (in `core/state_processor.go:490 ApplySigningTransaction`). Legacy XDPoSChain on xdc03 uses the mainnet default TIPSigning ≈ 3,000,000 → charges intrinsic gas (~3,400) for each tx to `0x...0089` (BlockSigners). Per V1 block: 4 sign-txs × 3,400 = 13,600 gas/block divergence. Same `--syncmode fast` + explicit `--fastsyncpivot{number,hash,root}` doesn't help because xdcSyncer.InsertChain still re-executes pre-pivot blocks.

**Fix applied** in `consensus/XDPoS/network_constants.go`: `localnet5151Constants.TIPSigning: big.NewInt(0)` → `big.NewInt(3000000)`. Devnet-5151 will never reach block 3M, so the gasless path stays INACTIVE, matching legacy.
